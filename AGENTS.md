# AGENTS.md

## Repository Purpose

This repository backs the GitHub profile page for `pfrankov`.

- `README.md` is the primary profile page in Russian.
- `README_EN.md` is the English version of the same profile page.
- `MENTORING.md` is supporting content and is not part of the required RU/EN sync unless a task explicitly says otherwise.

## Editing Rules

- Keep the profile tone personal, concise, and suitable for a public GitHub profile page.
- Preserve existing Markdown structure, section order, and link targets unless the task explicitly requires a structural change.
- Do not invent projects, achievements, dates, metrics, or links.
- Keep names of projects, channels, and brands in the form that makes the most sense for readers of each language.

## GitHub Project List Policy

- If `README.md` includes a section with GitHub projects, prefer the most recently created own repositories over repositories sorted by last activity.
- Do not use the README project list to repeat what GitHub pinned repositories already show.
- Treat pinned repositories on the profile page as the place for top or representative projects.
- Treat the README project list as the place for newly created work and fresh directions.
- Prefer non-fork, non-archived repositories.
- If several newly created repositories are viable, prefer the ones with clear descriptions and user-facing context.

## Required English Sync

- Treat `README.md` as the single source of truth.
- Any substantive change to `README.md` must be reflected in `README_EN.md` in the same work session.
- Sync direction is strictly one-way: `README.md` -> `README_EN.md`.
- Do not use `README_EN.md` as a source for updating `README.md` unless the user explicitly asks for that.
- Do not add new factual content to `README_EN.md` if it does not exist in `README.md`.

## Translation Guidance

- Translate by meaning, not word for word.
- Adapt wording to the context and placement of the text on a GitHub profile page.
- Keep the English version natural, concise, and easy to scan.
- Mirror additions, removals, and reordering from `README.md` in `README_EN.md` when they affect meaning or structure.
- Preserve intent and emphasis, even when a literal translation would sound unnatural.
